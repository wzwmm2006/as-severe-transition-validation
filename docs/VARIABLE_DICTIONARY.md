# Variable dictionary

| Internal name | Meaning | Unit or coding |
|---|---|---|
| `ava` | Aortic valve area by continuity equation | cm² |
| `vmax` | Peak aortic jet velocity | m/s |
| `mg` | Mean transvalvular gradient | mmHg |
| `lvef` | Left ventricular ejection fraction | % |
| `schema` | Structured reporting format | A or B |
| `SAVR` | Surgical aortic valve replacement | Procedure class |
| `TAVR` | Transcatheter aortic valve replacement | Procedure class |
| `cause` | Competing-risk state | 0 censored, 1 AVR/TAVR, 2 death |

Source column names required for authorized linkage are documented in code. No linkage identifiers are exported.
